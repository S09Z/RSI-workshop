# evals/

Eval gate for the RSI loop. Roadmap gate: the full system must beat the single agent by +15 points.
`graders/` and `tasks/heldout/` are PROTECTED. `results/` commits summaries; `results/raw/` is ignored.
No tasks are invented here; see the task format in `tasks/train/README.md`.
Configs: `configs/{single-agent,orch-worker,full-system}.yaml`.
