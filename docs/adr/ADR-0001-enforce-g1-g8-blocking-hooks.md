# ADR-0001: Enforce G1–G8 as blocking hooks before any self-modification

Status: Proposed
Date: 2026-11-25
Source: docs/report/rsi-research-report.md §9

- **Context.** All registered hooks are async loggers that always exit 0 (repo: `docs/baseline.md`); async hooks cannot gate [E414]. Only PreToolUse exit 2/deny and Stop/SubagentStop can block [E413]. Read/Edit deny misses subprocesses; the sandbox covers Bash but is off by default and fails open [E415][E416]. Test modification is the dominant Claude cheat [E405]. Prompts alone (`agents/*.md`) carry G2/G6/G7 today, and prompts are context, not enforcement [E201].
- **Options.** (a) Keep async logging, rely on prompts. (b) Synchronous PreToolUse command hooks for G2, G6, G7, G8 plus SubagentStop hooks for G1, G3, G4 and a G5 check; enable sandbox with `failIfUnavailable` for the Worker and Advisor. (c) Managed-settings deny rules only.
- **Decision.** (b), with (c) for static path denies where possible (managed settings cannot be overridden [E415]). Keep the owner's async logger for telemetry; add `blocked: true` events. Change `hooks/guardrails.yaml` to carry `enforced: false|true` per guardrail (human-approved; additive, does not weaken). Register the hooks with a proposed separate `scripts/install-hooks.sh`, human-run, which backs up `settings.json`; `scripts/install.sh` still never touches `settings.json`.
- **Consequences.** RSI may start only when X1 passes both layers (§8): hook-level 40/40 and live 16/16, each case counted only from a logged `blocked: true` event with its `guardrail` and `case_id`; the live layer is not deterministic. Some latency per tool call (not measured). G3/G4/G5 need prompt changes (`ran_at`, fail-first step) in `agents/worker.md`/`agents/orchestrator.md`. Live surfaces: after install, the repo's `agents/` and `skills/` are the live `~/.claude` config; they and `routing/` change only through a human-merged proposal branch, and `memory/advisor/` is writable only by the Advisor (G6). Path checks compare resolved real paths, because the repo path and the `~/.claude` path are aliases of the same files. The Harden work is done by a human, or by an agent system that is not pointed at this repo. Cost: 12–20 human hours + X1 ($6.00, at most $15.60 with reruns; 5 human hours).
