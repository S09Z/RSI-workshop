# Harden G3, G4, G5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add three blocking hooks that make the Worker's acceptance test self-verifying: G5 (the DONE_WHEN test must fail before the first Worker dispatch), G3 (a `WORKS` report is re-verified by re-running the test), G4 (`WORKS` evidence carries a fresh `ran_at`), with X1 hook-level fixtures.

**Architecture:** A shared module `hooks/lib/donewhen.py` parses the dispatch prompt, validates the test command against an allowlist, runs it with argv and no shell, and classifies the result. Each hook is a thin `common.run_hook` wrapper like G1/G8. A small per-task record file in the hook state dir links the G5 dispatch to the later G3/G4 check. Prompts in `agents/orchestrator.md` and `agents/worker.md` gain the fields the hooks read.

**Tech Stack:** Python 3 standard library only (`subprocess`, `shlex`, `dataclasses`, `json`, `re`, `datetime`), run as `python3 -I`; tests with `unittest`; pytest only as a runner that is exercised when installed.

**Spec:** `docs/superpowers/specs/2026-11-26-harden-g3-g4-g5-design.md` (approved 2026-11-26). Where this plan and the spec disagree, the spec wins; rulings are logged in the ledger.

## Global Constraints

- Blocking hooks exit 2 to deny; exit 1 does not block (`hooks/tests/fixtures/PROBE.md`).
- Every hook is inert unless `AGENT_WORKFLOW=1`, and fails closed (any error is a deny).
- Hooks never run a command the allowlist does not accept. Commands run with `shell=False`, `cwd` = git root, timeout `AGENT_DONEWHEN_TIMEOUT` (default `120` seconds).
- A deny is always logged as a `guardrail_hit` event with `guardrail`, `blocked: true`, `case_id`, `rule_version`. A deny never depends on the log being writable (`common.run_hook` already does this).
- `enforced` stays `false` in `hooks/guardrails.yaml`. Nothing is registered in `~/.claude/settings.json`.
- `g8_capture.py`, `g8_worker_tests.py`, `g2_*.py`, `g6_*.py`, `g7_*.py` are not modified.
- Rule versions: `g5-v1`, `g3-v1`, `g4-v1`.
- Git commit trailer for commits in this plan: `Co-Authored-By: Claude Haiku 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Test runner absent on the machine.** `pytest` not installed: G5 must deny (classified `error`), not allow. Pinned in Task 2 and Task 4.
2. **Test file that is a symlink to outside the git root.** Path check uses real paths. Pinned in Task 1.
3. **Dispatch record gone before the Worker returns** (state pruned after TTL, or a missing `TASK:` id). G3/G4 deny rather than allow. Pinned in Task 3 and Task 5.
4. **A timed-out test run that leaves children alive.** The process group is killed. Pinned in Task 2.
5. **Test output that contains a secret or a huge log.** The reason string carries only the last 800 characters, and no environment values. Pinned in Task 2.

### Task 1: Dispatch parsing and command validation

**Files:**
- Create: `hooks/lib/donewhen.py`
- Test: `hooks/tests/test_donewhen.py`

**Interfaces:**
- Consumes: nothing.
- Produces:
  - `@dataclass Dispatch(task: str, kind: str, argv: list[str], files: list[str])`. `kind` is `"test"` or `"write-test"`. `argv` is `[]` when `kind == "write-test"`. `files` are real paths.
  - `parse(prompt: str, cwd: str) -> Dispatch`. Raises `ValueError` with a reason when the task id `[Tn]` is missing at the start of the prompt's first line, or when neither `DONE_WHEN_CMD:` nor `TASK_KIND: write-test` is present. Reads `DONE_WHEN_FILES:` (comma-separated) and `DONE_WHEN_CMD:` (one line, parsed with `shlex.split`).
  - `validate(d: Dispatch, root: str) -> str | None`. Returns `None` if allowed, else a reason. Allowed shapes only: `pytest …` and `python3 -m pytest …` and `python3 -m unittest …`. Allowed options: pytest `-q -v -x --tb=short|line|no|long --maxfail=N -k EXPR -m EXPR`; unittest `-v -f -k EXPR`. Every positional must be a file (pytest may append `::node`) whose real path is listed in `d.files` and lies inside `root`. Any other token, any option not listed, `-p`, `-c`, `--rootdir`, `--junitxml`, `-o`, or any shell metacharacter in the raw line (`;&|<>$\`()`) → reason. `write-test` dispatches always return `None` from validate.
  - `git_root(cwd: str) -> str | None`: first ancestor (inclusive) with a `.git` entry.

### Task 2: Run and classify the test command

**Files:**
- Modify: `hooks/lib/donewhen.py`
- Test: `hooks/tests/test_donewhen.py` (new class `RunClassify`)

**Interfaces:**
- Consumes: `Dispatch`, `validate` from Task 1.
- Produces:
  - `@dataclass RunResult(status: str, returncode: int | None, passed: int, failed: int, tail: str)`. `status` ∈ `"passed" | "failed" | "error"`.
  - `run(d: Dispatch, root: str, timeout: float | None = None) -> RunResult`. Calls `validate` first; if it returns a reason, returns `RunResult("error", None, 0, 0, reason)` without running anything. Otherwise runs `d.argv` with `shell=False`, `cwd=root`, `stdin=DEVNULL`, `start_new_session=True`, scrubbed env (`PATH`, `HOME`, `LANG`, `LC_ALL`, `TMPDIR`, `VIRTUAL_ENV`, plus `PYTHONDONTWRITEBYTECODE=1`), and for pytest inserts `-p no:cacheprovider -o addopts=` after the runner word. On timeout kills the process group (`os.killpg`) and returns `error` with `tail` = `"timeout"`.
  - `tail` = last 800 characters of combined stdout+stderr; never includes environment values.
  - Classification: `passed` = returncode 0 and `passed >= 1` and `failed == 0`; `failed` = at least one test failed or errored (pytest: returncode 1; unittest: `FAILED` line); `error` = everything else, including pytest exit 2 (collection error), exit 4 (usage), exit 5 (no tests collected), a missing runner binary, timeout, or unparseable summary, and any run with `passed == 0 and failed == 0`.
  - Counts: pytest from the final line `N passed`, `N failed`, `N error(s)`; unittest from `Ran N tests` and `FAILED (failures=a, errors=b)` / `OK`.
  - Also `timeout_seconds() -> float`: reads `AGENT_DONEWHEN_TIMEOUT`, default `120`, invalid values fall back to `120`.

### Task 4: G5 test-first gate hook

**Files:**
- Create: `hooks/g5_test_first.py`
- Test: `hooks/tests/test_g5.py`

**Interfaces:**
- Consumes: `parse`, `validate`, `run`, `RunResult`, `write_record`, `read_record`, `git_root`, `now_iso` from Tasks 1–3; `common.run_hook`, `common.Decision`, `common.role` from `hooks/lib/common.py`.
- Produces: the hook script. Guardrail `G5`, rule_version `g5-v1`.

Behaviour (`main(event)`):
1. `event.tool_name != "Agent"` or `tool_input.subagent_type != "worker"` → `None` (allow, no log).
2. `parse(prompt, cwd)` raises → `Decision(False, "G5", "G5: dispatch needs a task id [Tn] and DONE_WHEN_CMD (or TASK_KIND: write-test): <reason>")`.
3. `kind == "write-test"` → write record with `argv=[]`, `cmd_text=""`, allow with `{"log": True}` (logged as allowed with `guardrail` G5).
4. `git_root(cwd)` is `None` → deny `G5: no git root found from <cwd>`.
5. Existing record for the task (`read_record`) and not stopped: the new `argv` and `files` must equal the recorded ones. Mismatch → deny `G5: DONE_WHEN for <Tn> changed after the first dispatch (locked)`. Equal → allow (re-dispatch, no re-run).
6. Otherwise `res = run(d, root)`:
   - `failed` → write record, allow with `{"log": True}`.
   - `passed` → deny `G5: <Tn> DONE_WHEN already passes; the test does not check the new behaviour`, with `tail`.
   - `error` → deny `G5: DONE_WHEN for <Tn> did not run as a failing test (<status>): <tail>`.
   The reason string is truncated to 800 characters of tail.

Session id comes from `event["session_id"]`, default `"nosession"` as in G8.

### Task 5: G3 re-run hook

**Files:**
- Create: `hooks/g3_rerun_done_when.py`
- Test: `hooks/tests/test_g3.py`

**Interfaces:**
- Consumes: `read_record`, `newest_open`, `mark_stopped`, `run`, `RunResult`, `Dispatch`, `parse`-free reading of the record (`argv`, `files`, `root`, `kind`, `task`); `common.run_hook`, `common.Decision`.
- Produces: the hook script. Guardrail `G3`, rule_version `g3-v1`.

Behaviour (`main(event)`, SubagentStop):
1. `agent_type != "worker"` → `None`.
2. `stop_hook_active` true → `Decision(True, "G3", "retry_cap", {"log": True})`.
3. Final message from `final_message(event)`: reuse the same approach as G1 (copy the `final_message` helper, not import from G1). No text → `None` (G1 already denies empty reports).
4. Parse `STATUS:` in the `=== WORKER REPORT ===` block. Not `WORKS` → `None`.
5. Task id: the `TASK:` line's first `[Tn]`. If present, `read_record(sid, task)`. If absent, `newest_open(sid)`. No record → deny `G3: no DONE_WHEN record for this WORKS report; cannot verify`.
6. `kind == "write-test"` → `Decision(True, "G3", "write-test skipped", {"log": True})`.
7. `res = run(Dispatch(task, kind, argv, files), root)`:
   - `passed` → `Decision(True, "G3", ..., {"log": True})`, mark stopped.
   - `failed` or `error` → deny `G3: WORKS for <Tn> but DONE_WHEN re-run is <status>: <tail>`, do not mark stopped.
8. Mark stopped on allow only.

5. `ran_at < dispatched_at` → deny `G4: ran_at is before this task was dispatched`.
6. `ran_at > now + 5 seconds` → deny `G4: ran_at is in the future`.
7. Otherwise allow with `{"log": True}`. Do not mark the record stopped (G3 owns that).
